# Modeling guides

[Model files](../models.md) is the reference, object by object. These guides go the other way: they start from something a real system does and show how to model it, with a complete model you can paste into a file and run, what to look at in the results, and the usual mistakes.

| Guide | When the system has... |
|---|---|
| [Breakdowns and repairs](failures.md) | machines that fail, jam or need tool changes |
| [Shifts and working hours](shifts.md) | shifts, weekends, opening hours, overtime, busier hours |
| [Shared operators and tools](shared-resources.md) | people or tools that several stations share, or a cap on work in process |
| [Rework and scrap](rework.md) | inspection that sends parts back, or throws them away |
| [Stock and restocking](restocking.md) | stock that runs down and is reordered |
| [Vehicles](vehicles.md) | forklifts, AGVs or carts carrying parts between places |
| [Priorities, due dates and impatience](priorities.md) | urgent parts, lines served in an order, people who give up |
| [Choosing distributions](distributions.md) | times to model from data, or without data |
| [The templates](templates.md) | a starting point close to your system |

Before a model is used for a decision, go through the [modeling checklist](checklist.md).
